# design-system

UI の見た目は、design-vault のデザイントークン（CSS 変数）だけで組み立てる。トークンはパターンごとに分かれていて、各パターンの値と使い分けは `references/<パターン名>/DESIGN.md` にある。このファイルには値を書かない。

## パターンを選ぶ

1. 利用側の `CLAUDE.md` などで指定されたパターンを使う（例: 「design-system の composer パターンに従う」）
2. 指定がなければ、`references/` 配下のフォルダ（＝パターン名）を利用者に示して、どれを使うか聞く。勝手に選ばない
3. 選んだパターンの `DESIGN.md` を読んでから書き始める。ほかのパターンのトークンを混ぜない
4. ボタン・入力欄・リストの行・パネル・バッジを作るときは `references/components.md` の割り当てに従う（パターンに依らない）

## 全パターン共通のルール

- 色・文字・余白・角丸は、必ず CSS 変数（`var(--...)`）で指定する。色コードや px を直書きしない
- 当てはまるトークンがないときは、近い値を直書きして済ませない。いちばん近いトークンを使い、トークンが足りないことを利用者に伝える
- トークンは名前の意味で選ぶ。値が近いという理由で、意味の違うトークンを流用しない（例: 枠線の色に文字色のトークンを使わない）
- 文字のスタイルは `typography.*` をまとめて使う（`font: var(--typography-...)`）。font-size や line-height を個別に指定しない
- 文字と地の組み合わせは、DESIGN.md がコントラストを確かめたと書いている組を優先する。それ以外の組で文字を載せるときは、読めるか利用者に確かめる

## Do / Don't

| Do | Don't |
| --- | --- |
| `color: var(--color-text-muted);` | `color: #5a6170;` |
| `padding: var(--space-md);` | `padding: 15px;` |
| `font: var(--typography-body-sm);` | `font-size: 14px; line-height: 1.6;` |
